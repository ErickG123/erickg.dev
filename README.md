## 🛠️ O Arsenal de Engenharia (Features)

Este projeto foi construído para demonstrar domínio em arquitetura escalável, testes e experiência do usuário (UX):

*   **PWA (Progressive Web App):** Instalável em dispositivos móveis, rodando em tela cheia (Standalone) para simular um emulador nativo.
*   **Acessibilidade e i18n:** Suporte a múltiplos idiomas (`ngx-translate`) e modo "Corporate Glasses" para recrutadores, alternando o tema e melhorando a acessibilidade (a11y).
*   **Testes Automatizados (Jest):** Lógicas de negócio e componentes protegidos por suítes de testes unitários com Jest.
*   **CI/CD Pipeline:** Esteira de Continuous Integration via GitHub Actions garantindo que nenhum código quebrado seja mesclado na `main`.
*   **Telemetria Avançada:** Eventos customizados rastreados via Vercel Analytics.
*   **Save State:** Utilização de `localStorage` para gerenciar as preferências do usuário e destravar conquistas (*Achievements*).

## 🗂️ Inventário de Projetos (Highlights)

O sistema de inventário hospeda demonstrações interativas de aplicações complexas:

1.  **The Architect's Forge:** Sistema de dashboards dinâmicos com layouts configuráveis e renderização de grids em tela cheia. Demonstração interativa de CLI embutida no DOM.
2.  **Cyber Sleuth Toolkit:** Interface de diagrama de fluxo baseada em nós para mapeamento de regras de processo.
3.  **Network Guardian Node:** Integração de API de Business Intelligence com backends em bancos de dados relacionais.

## 💻 Como Compilar o Sistema Localmente

Para rodar este cartucho na sua máquina local, você precisará do Node.js (v20 LTS recomendado).

```bash
# 1. Clone o repositório
git clone https://github.com/ErickG123/erickg.dev.git

# 2. Entre na pasta do projeto
cd erickg.dev

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm start
```
O sistema estará rodando em http://localhost:4200/.

## 🛡️ Rodando a Suíte de Defesa (Testes)
Para validar a integridade do código utilizando o Jest:

```bash
npm run test
```
